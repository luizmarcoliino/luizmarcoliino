#### Construindo agora: [Poppings](https://poppings.com.br)

Plataforma web para empresas criarem, aprovarem e padronizarem seus **procedimentos operacionais padrão (POPs)**, o passo a passo das tarefas do dia a dia, para que a equipe execute tudo sempre do mesmo jeito.

- **Editor de procedimentos** com passos, fotos e observações;
- **Fluxo de aprovação:** nada é publicado sem revisão do gestor;
- **Papéis e setores:** gestores aprovam, editores escrevem, colaboradores leem e confirmam;
- **Acompanhamento da equipe:** quem leu e confirmou cada procedimento;
- **Histórico de alterações** e dados isolados por empresa...
